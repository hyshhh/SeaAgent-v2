# SeaAgent

面向海域船舶监控的轨迹记忆闭环多智能体系统。系统以单段监控视频为工作对象，将船舶检测、跨帧跟踪、正式关键帧筛选、舷号聚合、统一多模态特征检索和闭环问答组织为一条可追溯链路。

## 核心链路

```text
监控视频
  → YOLO 检测与 ByteTrack 跟踪
  → 每十帧生成候选船舶裁剪图
  → 临时池质量预筛
  → Qwen3-VL-4B 单帧判断舷号可读性、舷号和外观描述
  → 正式关键帧池，单轨迹最多六帧
  → Qwen3-VL-Embedding-2B 生成 2048 维归一化特征
  → 轨迹记忆与正式关键帧特征库
  → 规划智能体—观察智能体—反思智能体闭环问答
```

先验库中的每张参考图独立生成特征并写入独立的先验库特征索引。用户描述在查询时即时编码，可直接与正式关键帧进行图文匹配；先验库参考图可与正式关键帧进行图图匹配。

正式关键帧替换采用一致性提交：先生成新图像和特征，再同步更新关键帧表与 FAISS 索引；任一步失败均恢复关键帧表、索引文件和索引清单，成功后才删除旧关键帧图像。

## 三层记忆

- **感知证据**：原视频、轨迹框序列和按轨迹裁剪的目标船片段，用于回放核验。
- **轨迹记忆**：轨迹起止时间、聚合舷号、轨迹描述、正式关键帧及其特征状态。
- **先验知识**：舷号库项、描述、多视角参考图及先验库特征索引。

问答过程只在同一数据库中追加会话、轮次和证据审计记录，不复制视频或轨迹记忆。

## 三智能体闭环

- **规划智能体**：识别五类问题，生成最短原子工具计划。
- **观察智能体**：执行白名单工具，记录轨迹、时间、特征分数和证据编号。
- **反思智能体**：检查证据是否充分、冲突或缺失，决定回答、继续规划或无法确认。

三个角色共享同一个 `Qwen3-VL-4B` 推理服务，不需要部署三个模型实例。`Qwen3-VL-Embedding-2B` 作为独立的统一多模态特征模型在本地延迟加载。

## 支持的问题

1. 舷号是否出现及出现时间。
2. 按外观描述查找目标船。
3. 指定时间段内查找未在先验库中的船。
4. 指定时间段内查找在先验库中的船。
5. 指定时间段内统计去重后的船舶数量。

网页回答同时展示结论、工具调用链和最多三条关键证据，避免一次弹出过多视频或图片。

## 项目结构

```text
agent/          三智能体控制器
config/         四份运行配置与配置加载器
memory/         统一表结构和数据访问
pipeline/       检测、跟踪、双池关键帧和舷号聚合
services/       Qwen3-VL-4B 与统一多模态特征服务
tools/          面向智能体的原子工具
vector_store/   两类 FAISS 精确点积索引
web/            网页、接口、H.264、WebRTC 和摄像头链路
data/           运行时轨迹记忆、先验库和索引
```

## 快速启动

完整环境部署见 `SETUPREADME.md`，最短命令见 `SMALLREADME.md`。

```bash
pip install -e .
python -m web.app
```

默认访问：`http://127.0.0.1:8000`

处理单个视频：

```bash
python -m pipeline.cli data/videos/example.mp4 --demo --output output/result.mp4
```

## 配置

项目只使用四份配置文件：

- `config/app.yaml`：网页、模型和存储路径。
- `config/yolo.yaml`：检测器和跟踪器。
- `config/pipeline.yaml`：双池、舷号聚合、检索阈值和智能体轮次。
- `config/prompts.yaml`：单帧识别、角色和灰区核验提示词。

正式关键帧与先验库参考图均使用 `2048` 维、二范数归一化特征。两类索引均为 `IndexIDMap2(IndexFlatIP(2048))`，点积等价于余弦相似度。

## 先验库一致性

- 每个舷号最多保存六张参考图。
- 新建、编辑、追加或删除参考图后完整重建先验库索引。
- 特征生成或索引写入失败时回滚库项、参考图文件和索引。
- 正式关键帧替换时删除旧活动向量，再提交新关键帧记录和向量。
- 问答阶段直接舍弃 `is_embedded=false` 的关键帧。

## 网页功能

- 上传视频并启动检测、跟踪和轨迹记忆构建。
- 使用浏览器摄像头、服务器摄像头或网络视频流。
- 保留 H.264、逐帧图像流和 WebRTC 输入输出链路。
- 管理舷号库项及一至六张多视角参考图。
- 执行五类闭环问答并查看规划、观察、反思和可视证据。

## 运行数据

运行时数据位于 `data/`：

- `data/memory/`：轨迹、正式关键帧和问答审计记录。
- `data/registry/`：先验库项与参考图。
- `data/indexes/`：正式关键帧和先验库两个特征索引。
- `data/videos/`：上传的监控视频。

默认每次启动视频流水线会清空当前视频的轨迹记忆，但不会清空先验库。
